# HR 出勤戰情室－使用者操作手冊

## 1. 系統用途

HR 出勤戰情室用於快速查看員工出勤狀況、部門出勤率及異常人員，並可透過 Excel 匯入更新資料。

## 2. 開啟系統

1. 使用瀏覽器開啟 HR 戰情室網址。
2. 建議使用最新版 Chrome 或 Microsoft Edge。
3. 若畫面沒有最新資料，先重新整理網頁。

## 3. 匯入 Excel

1. 點選「匯入 Excel」。
2. 選擇 HR 出勤資料 Excel 檔案（`.xlsx` / `.xls` / `.csv`）。
3. 等待系統完成資料解析。
4. 儀表板會依新資料重新計算。

### Excel 欄位

系統主要依賴以下欄位：

- 部門
- 部門名稱
- 工號
- 姓名
- 日期
- 上班判讀
- 下班判讀
- 班別
- 班別名稱

## 4. 出勤狀態判讀

目前規則：

| 上班判讀 | 系統狀態 |
|---|---|
| 正常 | 正常 |
| 休息日 | 正常 |
| 免刷 | 正常 |
| 其他值 | 異常 |

> 注意：實際出勤率若要排除休息日，應以「應到人數」作為分母，而不是單純以全部資料筆數計算。

## 5. 儀表板功能

### KPI

- 總人數：目前資料中的員工人數。
- 正常人數：依目前出勤判讀規則歸類為正常的人員。
- 異常人數：被判定為異常的人員。
- 出勤率：依系統目前設定的計算方式顯示。

### 篩選

可依部門、出勤狀態及員工關鍵字縮小資料範圍。

### 異常名單

異常人員會顯示於異常追蹤區域，HR 可進一步確認刷卡、請假、缺勤或其他處理狀態。

## 6. 建議作業流程

1. 每日取得最新刷卡資料。
2. 確認 Excel 欄位格式沒有變更。
3. 匯入 Excel。
4. 先查看總體異常人數。
5. 依部門檢查異常分布。
6. 開啟異常名單確認個別人員。
7. 必要時回到原始 HR 系統確認資料。

## 7. 注意事項

- 不要修改 Excel 欄位名稱，除非系統已同步調整。
- 不要將含有員工個資的 Excel 上傳到公開 GitHub Repository。
- 戰情室屬於統計與輔助查詢工具，正式人事判定仍應以公司正式 HR／出勤系統及相關規章為準。
- 若資料異常，先確認原始 Excel 是否正確，再檢查匯入結果。

## 8. 常見問題

### Q1. 匯入 Excel 後資料沒有更新？

重新選擇正確檔案，確認檔案副檔名及欄位名稱，並重新整理瀏覽器。

### Q2. 為什麼某些人被列為異常？

請先查看該筆資料的「上班判讀」。目前只有「正常」、「休息日」、「免刷」會歸類為正常，其餘值會歸類為異常。

### Q3. 可以把正式員工資料放進 GitHub 嗎？

不建議。員工姓名、工號、出勤與請假資料屬於應妥善保護的個人資料，正式環境應採取適當的存取控制與資料保護措施。
