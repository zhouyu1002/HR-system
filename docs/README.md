# HR 戰情室文件中心

本目錄集中放置 HR 出勤戰情室的系統文件、資安規範、維運資料與使用者文件。

## 文件分類

- `USER-MANUAL.md`：使用者操作手冊
- `SYSTEM-OVERVIEW.md`：系統架構與功能說明
- `SECURITY.md`：資安與個資保護注意事項
- `OPERATIONS.md`：日常維運與故障排除
- `CHANGELOG.md`：版本與功能變更紀錄

## 資料安全原則

本專案的 Excel 匯入功能以瀏覽器本機處理為設計方向。正式環境請避免將含有員工姓名、工號、出勤紀錄等個人資料的原始 Excel 直接提交至 GitHub Repository。

正式上線前，建議依公司個資保護、資訊安全及權限管理規範進行部署與審查。
