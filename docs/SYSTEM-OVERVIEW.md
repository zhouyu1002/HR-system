# 系統說明

## 1. 系統定位

HR 出勤戰情室是一個以 Web 技術建立的出勤資料視覺化工具，用於協助 HR 快速掌握人員與部門出勤狀況。

## 2. 技術架構

- Frontend：React
- Build：Vite
- Excel 解析：SheetJS (`xlsx`)
- 圖表：Recharts
- 程式碼管理：GitHub
- 部署：GitHub Pages / 可改部署至公司內部 Web Server

## 3. 資料流程

`Excel → 瀏覽器解析 → 出勤狀態判讀 → 統計 → 儀表板`

目前設計方向為在瀏覽器端解析匯入檔案，不需要把原始員工 Excel 上傳到應用程式後端。

## 4. 主要功能

- Excel 匯入
- 總人數統計
- 正常／異常統計
- 出勤率
- 部門出勤分析
- 異常人員追蹤
- 部門與關鍵字篩選

## 5. 後續擴充方向

- 日期區間查詢
- 部門鑽取
- 異常原因分析
- 權限登入
- 操作紀錄
- 公司內網部署
- 與正式 HR／ERP 系統介接
