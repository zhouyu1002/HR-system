# 資安與個資保護說明

## 1. 個人資料

出勤資料可能包含姓名、工號、部門、刷卡時間、請假及缺勤資訊，應視為需要保護的員工資料。

## 2. Repository 使用原則

- 不要將真實員工 Excel 提交至公開 Repository。
- 不要把帳號密碼、API Token、憑證或私鑰寫入程式碼。
- 測試資料應優先使用去識別化或假資料。
- GitHub Repository 應只保存程式碼與非敏感文件。

## 3. 瀏覽器端匯入

目前匯入功能以瀏覽器本機解析 Excel 為設計方向。正式上線前仍應透過瀏覽器開發者工具、網路封包及部署環境確認資料沒有被送往不必要的第三方服務。

## 4. 正式環境建議

若系統用於公司正式人事資料，建議：

1. 優先部署於公司內部網路或受控的 Web Server。
2. 使用 HTTPS。
3. 導入公司既有帳號／身分驗證機制。
4. 依職務設定最小必要權限。
5. 對管理員操作建立稽核紀錄。
6. 定期更新前端套件與作業系統。
7. 建立備份、復原及資安事件處理流程。

## 5. 資料生命週期

應明確定義資料來源、保存期限、使用目的、存取人員與刪除方式，並依公司個資及資訊安全規範執行。

## 6. 重要提醒

GitHub Pages 適合展示前端網站，但若網站內容或其後端服務涉及真實員工個資，不應只依賴「網址不公開」作為安全控制。正式系統應搭配身分驗證、授權及公司網路安全措施。
